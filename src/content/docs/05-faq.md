按客户端里看到的报错对号入座。

## 「无效的令牌」/ 401 Unauthorized

密钥本身不被接受：

- 密钥复制不完整（少了字符），或混入了空格、引号；
- 密钥被**禁用**（提示「该令牌状态不可用」）、已删除或已过期；
- 用错了密钥：把上游厂商的 Key 当成了本站密钥。客户端里只能填集智AI Lens 签发的 `sk-` 密钥；
- 请求头格式：应为 `Authorization: Bearer sk-xxx`。

处理：到控制台「API 密钥」页确认密钥状态为 **已启用** 且未过期；不行就删掉重建。

## 「该令牌无权访问模型 X」/「该令牌无权访问任何模型」

密钥设置了**模型限制**，而当前调用的模型不在白名单内。到「API 密钥」页编辑该密钥，把模型加入模型限制，或清空限制。

## 「您的 IP 不在令牌允许访问的列表中」

密钥设置了 **IP 白名单**，当前出口 IP 不在其中。常见于客户端走代理、更换网络后触发。编辑密钥的白名单（支持 CIDR），或暂时清空白名单。

## 「分组 X 下模型 Y 无可用渠道（distributor）」/ 503

网关侧暂时没有能承接这次请求的渠道，常见原因按顺序排查：

1. **模型名拼错**：对照 `GET /v1/models` 返回的模型名逐字检查；
2. **模型存在，但你用的协议没有渠道**：同一个模型可能只对某类端点开放（例如只支持 `/v1/chat/completions`，不支持 `/v1/messages`）。换一种客户端协议试试（如 Claude Code 报此错时，改用 OpenAI 兼容客户端调用同一模型）；
3. **渠道临时不可用**：上游故障或被禁用。稍后重试，仍不行就联系管理员。

## 「用户额度不足, 剩余额度: X」

账户余额不够支付这次请求：

- 到控制台 **钱包** 充值，或用 **兑换码** 兑换额度；
- 如果只是某次长对话/大任务预扣费失败（「预扣费额度失败…」），可以把请求的 `max_tokens` 调小后重试；
- 密钥本身设了配额上限且已用尽时，需在「API 密钥」页调大该密钥配额或改为无限配额。

## 404 Not Found

接口路径不对，九成是 Base URL 填错：

- OpenAI 兼容客户端的地址必须**带** `/v1`：`https://th.jimei.cn/v1`；
- Anthropic 协议客户端（Claude Code、Anthropic SDK）的地址**不带** `/v1`：`https://th.jimei.cn`；
- 自建部署的其他站点地址不适用于本站，客户端里请统一填 `th.jimei.cn`。

## Claude Code 配置不生效

- `~/.claude/settings.json` 改完后需要重启 Claude Code；
- 确认 `env` 里写的是 `ANTHROPIC_AUTH_TOKEN`（不是 `ANTHROPIC_API_KEY`）；
- 环境变量方式只对当前终端会话有效，新开终端要重新 `export` 或写入 shell 配置文件；
- 用 `claude -p "你好"` 快速验证。

## 密钥疑似泄露怎么办

1. 控制台「API 密钥」页先 **禁用** 该密钥（立即止血，客户端开始收到 401）；
2. 查看 **使用日志**，确认泄露期间的异常调用；
3. 确认后 **删除** 该密钥，创建新密钥并更新到客户端。

## 找不到答案

把以下信息发给管理员，可以快速定位问题：

- 请求的完整端点路径（如 `/v1/chat/completions`）；
- 客户端里配置的 Base URL 与模型名；
- 报错的 HTTP 状态码与完整错误文案；
- 大致发生时间（用于在管理端日志中检索）。
