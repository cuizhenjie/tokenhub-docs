所有客户端里填的「API Key / Token / 密钥」，都是集智AI 控制台签发的 `sk-` 开头字符串。上游厂商的 Key 由管理员在服务端配置，**用户侧永远只使用集智AI 签发的密钥**。

## 创建密钥

1. 打开[控制台](https://th.jimei.cn)并登录。没有账号先注册，或联系管理员开通。
2. 左侧菜单进入 **API 密钥**。
3. 点击 **创建 API 密钥**，按需填写：

| 分区 | 字段 | 说明 |
| --- | --- | --- |
| 基本信息 | 名称 | 便于区分用途，如 `claude-code-笔记本` |
| | 数量 | 一次批量创建多个密钥 |
| 额度设置 | 配额 | 该密钥最多可消耗的额度；勾选 **无限配额** 后只受账户余额限制 |
| | 过期时间 | 永不 / 1 小时 / 1 天 / 1 个月 / 自定义；建议设置过期时间 |
| 高级设置 | 分组 | 决定路由与计费倍率，一般保持默认 |
| | 模型限制 | 限定该密钥只能调用指定模型 |
| | IP 白名单 | 限制调用来源 IP，支持 CIDR 表达式 |
| | 跨分组重试 | 该分组无可用渠道时是否允许尝试其他分组 |
| | 允许查询用户额度 | 允许该密钥调用余额查询接口 |

4. 点击 **提交**。弹出密钥后 **立即复制并妥善保存**——完整密钥只显示这一次，之后无法再查看，只能删除后重建。

## 管理密钥

在「API 密钥」列表中，每个密钥都可以：

- **启用 / 禁用**：临时停用，不删除；客户端会立即收到 401。
- **编辑**：修改名称、配额、过期时间和各项限制。
- **删除**：彻底吊销。
- 查看每个密钥的剩余配额、已用额度和状态。

## 安全约定

- 密钥不要写进代码仓库、文档或聊天记录；示例代码一律用 `sk-xxxxxxxx` 之类的占位符。
- 一个客户端（或一台设备）使用一个密钥，按用途命名，便于单独吊销。
- 密钥疑似泄露：先 **禁用** 止损，确认影响面后再删除重建。
